# Quickstart: Drawer UX Hardening

## Run Tests

```powershell
node --test tests\option-b-upload-regression.test.js
```

## Manual Smoke Test

1. Open `index.html`.
2. Open the drawer and verify it is wider on desktop with stronger overlay blur.
3. Confirm drawer sections have subtly distinct backgrounds.
4. Upload multiple JSON files and verify unique files store.
5. Upload a duplicate filename and verify the alert appears and upload is skipped.
6. Compare two warehouse engines and verify the prominent overall score appears.
7. Hover a graph node for 10 seconds and verify the tooltip disappears.
